BASKETBALL - Android project

App name: Basketball
Application ID: com.muhammadyounas.basketball
Target SDK: 36

How to build:
1. Install Android Studio.
2. Open this folder as an existing Android Studio project.
3. Let Gradle sync and install any requested SDK components.
4. Test on an Android phone or emulator.
5. For Google Play: Build > Generate Signed Bundle / APK > Android App Bundle.
6. Create/select a release keystore and build the signed .aab.
7. Upload the .aab to Google Play Console.

The game is bundled as app/src/main/assets/Basketball.html and runs locally in a WebView.
